# 🏥 MediCitasWeb — Sistema de Gestión de Citas Médicas

Sistema web desarrollado para la gestión integral de citas médicas, orientado a optimizar la interacción entre pacientes, personal médico y administración clínica mediante una plataforma moderna, segura y escalable.

---

## 🚀 Descripción del Proyecto

**MediCitasWeb** es una aplicación web desarrollada bajo arquitectura MVC que permite:

* Registro y autenticación de usuarios
* Gestión de pacientes
* Agendamiento de citas médicas
* Administración de usuarios y roles
* Control centralizado desde panel administrativo
* Integración con servicios de inteligencia artificial

El objetivo principal es digitalizar y automatizar procesos clínicos tradicionales, reduciendo tiempos operativos y mejorando la experiencia del usuario.

## 🏗️ Arquitectura

El sistema sigue el patrón:

```
MVC (Model – View – Controller)
```

**Componentes principales:**

* **Models:** Gestión de entidades y lógica de datos
* **Views (.cshtml):** Interfaces dinámicas con Razor
* **Controllers:** Control del flujo de la aplicación
* **Entity Framework:** Acceso a datos
* **SQL Server:** Persistencia de información

---
